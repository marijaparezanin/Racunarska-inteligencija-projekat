Metrics Explanation:

  • Precision: Correct positives out of all positive predictions.
  • Recall: Actual positives correctly identified.
  • F1-Score: Harmonic mean of precision and recall.
  • Support: Number of true instances for each class.
  • Accuracy: Overall correctness.

Plot Explanation:

  • Bar Plot (Class Distribution & Predictions): Shows how many samples belong to each class, and how many of them were predicted correctly or incorrectly. Useful for visually inspecting whether the model is biased toward a certain class or struggles with imbalanced datasets.
  • Training vs Validation Loss: Displays how the model’s loss changes over epochs for both training and validation sets. A decreasing training loss with a stable or decreasing validation loss indicates learning progress. If validation loss diverges upward while training loss decreases, the model may be overfitting.
  • Confusion Matrix: Provides a breakdown of predictions vs. actual labels. Each cell shows how many samples of a true class were predicted as another class. Helps identify specific misclassifications (e.g., false negatives vs false positives).
  • ROC Curve: Plots the true positive rate (sensitivity) against the false positive rate across different thresholds. A curve closer to the top-left indicates stronger performance. The area under the curve (AUC) summarizes this performance.
  • MLP Loss Curve: This plot shows how the training loss of the Multilayer Perceptron changes over epochs. Each point represents the loss at the end of an epoch. A steadily decreasing loss indicates that the model is learning effectively. If the loss plateaus or starts increasing, it may signal underfitting, overfitting, or the need for adjustments in learning rate, regularization (alpha), or network architecture.
