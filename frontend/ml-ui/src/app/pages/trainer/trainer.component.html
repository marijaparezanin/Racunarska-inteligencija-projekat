1. Overview of the Model
I implemented a deep feedforward neural network, named DeepOptimizedNN, to classify diabetes indicators from structured patient data. This network is designed to handle both numerical and categorical features, capturing complex, non-linear relationships in the dataset. The model was built using PyTorch, which allows flexible layer construction, GPU acceleration, and fine-grained control over training.

2. Network Architecture
The neural network consists of multiple fully connected layers arranged sequentially:

  • Input Layer: Receives preprocessed features, scaled to zero mean and unit variance using StandardScaler.
  • Hidden Layers:
    • 128 neurons: BatchNorm, LeakyReLU, 30% Dropout
    • 64 neurons: BatchNorm, ReLU, 25% Dropout
    • 32 neurons: BatchNorm, ReLU
    • 16 neurons: ReLU only
  • Output Layer: Number of neurons equals the number of target classes (binary in this case), producing raw logits for CrossEntropyLoss.

Key points: progressively smaller layers compress features, BatchNorm stabilizes learning, and Dropout reduces overfitting.

3. Data Handling
Data is converted to NumPy arrays if needed. For large datasets, a maximum sample size can be enforced. Data is split into 80% training and 20% test sets, stratified by target class. Features are standardized, then wrapped in a TensorDataset and split into 90% training / 10% validation.

4. Training Procedure
The model is trained with AdamW optimizer and CrossEntropyLoss. Mixed-precision training is enabled for GPU acceleration. Training uses a batch size of 256 and early stopping based on validation loss.
Steps per batch:

  • Forward pass
  • Loss computation
  • Gradient backpropagation with scaling
  • Optimizer weight update

Average training and validation losses are tracked each epoch.

5. Evaluation
After training, the best-performing model predicts the test set. Evaluation includes:

  • Accuracy
  • Classification report (precision, recall, F1-score)
  • Visualizations: loss curves and bar plots of predicted vs actual classes

Note: raw logits are converted to class predictions using argmax.

6. Key Advantages
Deep architecture captures non-linear patterns. BatchNorm + Dropout ensures robust learning. Mixed-precision training accelerates GPU computation. Early stopping prevents unnecessary epochs. Metrics and visualizations allow interpretation and performance validation.

7. Takeaways
The network encodes complex feature interactions in a compressed representation. Proper preprocessing, stratified splitting, and scaling are critical. Combining deep learning techniques results in accurate and generalizable predictions, while visualizations provide insights for improvements.

Metrics Explanation:

  • Precision: Correct positives out of all positive predictions.
  • Recall: Actual positives correctly identified.
  • F1-Score: Harmonic mean of precision and recall.
  • Support: Number of true instances for each class.
  • Accuracy: Overall correctness.

Plot Explanation:

  • Bar Plot (Class Distribution & Predictions): Shows how many samples belong to each class, and how many of them were predicted correctly or incorrectly. Useful for visually inspecting whether the model is biased toward a certain class or struggles with imbalanced datasets.
  • Training vs Validation Loss: Displays how the model’s loss changes over epochs for both training and validation sets. A decreasing training loss with a stable or decreasing validation loss indicates learning progress. If validation loss diverges upward while training loss decreases, the model may be overfitting.
  • Confusion Matrix: Provides a breakdown of predictions vs. actual labels. Each cell shows how many samples of a true class were predicted as another class. Helps identify specific misclassifications (e.g., false negatives vs false positives).
  • ROC Curve: Plots the true positive rate (sensitivity) against the false positive rate across different thresholds. A curve closer to the top-left indicates stronger performance. The area under the curve (AUC) summarizes this performance.
  • MLP Loss Curve: This plot shows how the training loss of the Multilayer Perceptron changes over epochs. Each point represents the loss at the end of an epoch. A steadily decreasing loss indicates that the model is learning effectively. If the loss plateaus or starts increasing, it may signal underfitting, overfitting, or the need for adjustments in learning rate, regularization (alpha), or network architecture.
